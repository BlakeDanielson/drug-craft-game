# Product Context: Infinite Craft Enhanced

## 1. Problem Space

The original "Infinite Craft" game provides a simple, engaging loop of combining elements to discover new ones, often with surprising or humorous results generated by AI. However, it lacks persistence and a sense of shared community discovery. The existing "Drug Craft" project explored similar mechanics but with a specific, potentially limiting theme.

This project aims to capture the addictive simplicity of Infinite Craft while addressing its limitations by adding persistence, user identity, and a shared discovery experience.

## 2. Product Vision

To create the definitive "infinite combination" web game, offering:
*   An endless, engaging discovery process driven by creative AI.
*   A sense of community and achievement through global first discovery tracking.
*   A persistent experience tied to user accounts.
*   A clean, intuitive, and performant user interface.

## 3. Target Audience

*   Players who enjoy casual, creative, and discovery-based games.
*   Fans of the original Infinite Craft seeking a more persistent or enhanced experience.
*   Users interested in the emergent possibilities of AI-driven content generation.

## 4. Core User Experience Goals

*   **Simplicity:** Easy to understand and play immediately. Drag, drop, combine.
*   **Discovery:** The core loop should feel rewarding, surprising, and encourage exploration.
*   **Persistence:** Users should feel their progress (discoveries, identity) is saved and meaningful.
*   **Community:** The "First Discovery" feature should foster a subtle sense of shared participation and competition.
*   **Performance:** The interface and combination process should feel responsive.

## 5. Key Features & How They Work

*   **Element Combination:** Users drag elements from a sidebar onto a crafting area. Dropping one element onto another triggers a combination attempt.
*   **AI Generation (Dual):** When a new combination is attempted, the backend API checks if the result exists globally. If not, it queries either OpenAI or Gemini to generate a name and icon for the new element. This result is then stored.
*   **Global Discovery Tracking:** The API checks a central Supabase database. If a user creates a combination that results in an element never discovered before *globally*, they are marked as the "First Discoverer". This status is displayed to all users who subsequently create or view that element.
*   **User Accounts:** Users can sign up and log in using email/password (via Supabase Auth). This identity is linked to their "First Discoveries".
*   **Element Sidebar:** Discovered elements appear in a searchable/scrollable list for reuse in combinations.
*   **Minimalist UI:** The interface prioritizes the crafting area and element list, keeping controls minimal and intuitive.

## 6. Success Metrics (Potential)

*   User retention / session length.
*   Number of unique elements discovered globally.
*   User registration rate.
*   Feedback on the quality/creativity of AI generations.
